# Atelier Settings

Task 1 of the GDG Tech Wildcard frontend brief: real-time multi-tab preference synchronization.

- **Stack:** React 19, TypeScript, Vite
- **Palette:** coffee, paper, powder blue (from the supplied reference)
- **Source:** `apps/settings-sync`

## Run

```bash
cd apps/settings-sync
npm install
npm run dev
```

Full architecture, conflict-resolution notes, and testing instructions are added during the documentation phase.
